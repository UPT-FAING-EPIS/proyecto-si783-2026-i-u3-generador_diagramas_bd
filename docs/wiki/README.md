# FluxSQL Wiki

This folder is the versioned source for the GitHub Wiki content required by the evaluation rubric.

Recommended GitHub Wiki pages:

- `Home.md`: product summary and public URLs.
- `Features.md`: implemented features and scope.
- `Roadmap.md`: future versions and release dates.
- `Deployment.md`: VPS, No-IP, Caddy, Docker and GitHub Actions.
- `Releases-and-Packages.md`: desktop installer, VS Code extension and npm skill.
- `Agent-and-MCP.md`: Codex skill, MCP bridge, local memory and safe agent usage.
