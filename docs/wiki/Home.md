# FluxSQL

FluxSQL is a database diagram generator and local-first workbench for relational, NoSQL and graph database workflows.

Public URL:

```txt
https://fluxsql.sytes.net
```

Repository:

```txt
https://github.com/UPT-FAING-EPIS/proyecto-si783-2026-i-u3-generador_diagramas_bd
```

Main components:

- Web application for cloud projects, collaboration and public diagrams.
- NestJS cloud API for projects, diagrams, versions, comments and telemetry.
- Desktop app with Tauri and a FastAPI local sidecar.
- Local database connectors and safe schema inspection.
- MCP bridge for AI agents.
- VS Code extension for SQL-to-diagram workflows.
- npm-distributed Codex skill for repeatable agent workflows.
