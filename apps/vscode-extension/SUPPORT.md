# Support

For bugs, feature requests and publishing issues, use the FluxSQL repository issue tracker:

https://github.com/iovargasjeff/fluxsql-bd/issues

Please include:

- VS Code version
- FluxSQL extension version
- a minimal SQL sample that reproduces the issue
- expected output format: visual canvas, Mermaid, SVG or JSON

Do not include database passwords, private dumps, production data or credentials in support requests.
